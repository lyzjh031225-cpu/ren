# Quick Portal 浏览器插件（账号密码登录注册版）

当前版本实现了本地账号体系：
- 账号注册（账号 + 密码 + 确认密码）
- 账号密码登录
- 登录后门户欢迎页
- 退出登录
- 用户数据与登录会话持久化（扩展环境使用 `chrome.storage.local`）

> 说明：这是本地演示登录注册流程，暂未对接真实后端鉴权接口，也未做密码加密。

## 使用方式

1. 打开 Chrome，访问 `chrome://extensions/`
2. 打开“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前目录 `/workspace/ren`
5. 点击工具栏中的插件图标，先注册账号，再登录进入门户
