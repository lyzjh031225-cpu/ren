# Starter Portal（从零搭建版）

这是一个从零搭建的 Chrome 扩展最小模板，包含：

- Manifest V3 基础配置
- Popup 页面（HTML/CSS/JS）
- 本地存储示例（点击计数）

## 本地加载

1. 打开 Chrome，访问 `chrome://extensions/`
2. 打开“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前目录 `/workspace/ren`
5. 点击扩展图标，看到起步页并测试计数按钮

## 后续建议

你可以在此基础上继续加：
- 登录/注册
- API 请求
- 后台脚本（service worker）
- 选项页（options page）
